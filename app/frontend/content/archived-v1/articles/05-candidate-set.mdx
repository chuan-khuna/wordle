Each <Term>Feedback</Term> rules some words out. The words that survive are the <Term of="Candidate">Candidates</Term>, and all of them together are the <Term>Candidate Set</Term>.

A word is a Candidate if it could still be the Answer. The test is simple. Pretend the word *is* the Answer, and work out the Feedback every Guess in the <Term>State</Term> would have got. If every one of them matches what the game really said, the word is still a Candidate. If a single one is different, it is out.

Only words from the <Term>Answer List</Term> can be Candidates, even if a Guess was an odd word that could never be an Answer. At the start of a Game, before any Guess, the Candidate Set is the whole Answer List: 2,315 words.

## The same test in Python

The definition is already the code. Keep the Answer List words that would have produced every Feedback in the State, using the function from the Feedback Article:

```python
def candidates(state, answers):
    return [
        answer
        for answer in answers
        if all(feedback(guess.word, answer) == guess.feedback for guess in state)
    ]
```

The package does the same job, but much faster. Working out a Feedback again for every word on every step would be slow. Instead it looks each one up in a <Term>Feedback Matrix</Term>, a table of every Guess against every Answer that is scored once before any Game:

```python title="Narrowing the Candidates" {4-5}
def narrow(self, candidates: np.ndarray, guess: str, code: int) -> np.ndarray:
    """The Candidates that would have given Feedback Code `code` for `guess`."""
    row = self.guesses_vs_answers[self._guess_row[guess]]
    return candidates[row[candidates] == code]
```

The line that matters is the last one: keep the Candidates whose cell in the Guess's row equals the Feedback that came back.

## An even split

If a Guess split $N$ Candidates into $k$ groups of the same size, the next Candidate Set would have $N/k$ words. Real splits are never that even, and that is the problem the next Article looks at: how a Guess sorts the Candidate Set into groups.
