Game เดียวเล่าได้แค่เรื่องเดียว การเปรียบเทียบ Strategy ต้องดูทั้งหมด <Term>Benchmark</Term> เล่น <Term>Game</Term> สำหรับทุกคำใน <Term>Answer List</Term> ด้วยหนึ่ง <Term>Strategy</Term>: 2,315 Game

สำหรับแต่ละ Game เราจดค่า <Term>Guess Count</Term> คือจำนวน Guess ที่ใช้จน Win เมื่อรวมกันจะได้ <Term>Guess Distribution</Term> คือจำนวน Game ที่จบที่แต่ละ Guess Count บวกกับจำนวน Loss ค่าเฉลี่ยของทุก Game คือ <Term>Average Guess Count</Term> Game ที่แพ้ก็นับด้วย: Solver ทายต่อไปจนชนะ และ Guess Count นั้นถูกรวมเข้าค่าเฉลี่ย

```python
from collections import Counter

def benchmark(solver, opener, **strategy):
    counts = Counter()
    for answer in solver.answers:
        game = Game(answer)            # the Guess Limit is six
        candidates = solver.all_candidates()
        word = opener
        while not game.is_over:
            guess = game.guess(word)
            candidates = solver.narrow(candidates, guess.word, pack(guess.feedback))
            if not game.is_over:
                word = solver.suggest(candidates, **strategy).word
        counts[len(game.state) if game.is_won else "lost"] += 1
    return counts
```

Strategy คือการเลือกสามอย่าง: <Term>Guess Pool</Term> (Answer List หรือ Guess List) <Term>Search Scope</Term> (Candidate เท่านั้น หรือ All words) และ <Term>Ranking</Term> (Expected Information หรือ Expected Candidates) นั่นทำให้มี Strategy แปดแบบ แต่ละแบบเล่นจาก Opener ที่ดีที่สุดของมันเอง คือ Guess แรกที่ดีที่สุดใน Guess Pool ทั้งหมดของมัน นี่คือทั้งแปดแบบ:
