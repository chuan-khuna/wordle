ตอนนี้เราสร้าง <Term>Solver</Term> ได้แล้ว <Term>Strategy</Term> ของมันง่ายที่สุดเท่าที่มี: ในทุกขั้น ดู <Term>Candidate Set</Term> ปัจจุบัน ให้คะแนนทุก Guess ด้วย <Term>Expected Information</Term> แล้วเล่นคำที่ดีที่สุด วิธีนี้เรียกว่า greedy เพราะมันเลือก Guess ที่ดีที่สุดในตอนนี้ และไม่เคยวางแผนไกลกว่านั้น

แต่ละขั้นคือสามแนวคิดของ Part นี้ต่อกัน หา Candidate แบ่งพวกมันด้วยทุก Guess แล้วเล่นคำอันดับแรก Guess นั้นคือ <Term>Suggestion</Term>

```python title="The greedy choice" {11-14}
def suggest(
    self,
    candidates: np.ndarray,
    *,
    pool: Pool = "guesses",
    scope: Scope = "global",
    by: Rank = "bits",
) -> WordStats | None:
    """The Suggestion: the top-ranked Guess, or None if no Candidate is left."""
    # With one or two Candidates, guessing one of them is never worse.
    if 0 < len(candidates) <= 2:
        scope = "candidates"
    best = self.rank(candidates, pool=pool, scope=scope, by=by, top=1)
    return best[0] if best else None
```

Loop ที่ครอบมันสั้น ๆ ทาย Suggestion ตัด Candidate ให้แคบลงด้วย Feedback แล้วทำซ้ำ:

```python
game = Game("watch")
candidates = solver.all_candidates()
while not game.is_over:
    guess = game.guess(solver.suggest(candidates).word)
    candidates = solver.narrow(candidates, guess.word, pack(guess.feedback))
```

## Guess ที่ชนะไม่ได้

มีการตั้งค่าหนึ่งใน `suggest` ที่ส่งผลมาก: `scope` คือ <Term>Search Scope</Term> Solver จะค้นหาเฉพาะ Candidate ก็ได้ หรือจะค้นหา **All words** ใน Guess List ซึ่งรวมคำที่เป็น Answer ไม่ได้ก็ได้

การเล่นคำที่ชนะไม่ได้ฟังดูสิ้นเปลือง แต่มันอาจเป็นคำถามที่ดีที่สุด นี่คือเหตุผล ใน Game ที่ Answer คือ <Word>watch</Word>

ก่อนอื่น Solver ใช้การตั้งค่าแบบแคบ คือ Candidate เท่านั้น และเลือก Guess จาก Answer List ซึ่งเป็น <Term>Guess Pool</Term> ของมัน ลองเดินดูทีละขั้น:
