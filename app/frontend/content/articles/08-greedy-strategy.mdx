Now we can build the <Term>Solver</Term>. Its <Term>Strategy</Term> is the simplest possible one. At each step, it takes the current <Term>Candidate Set</Term>, calculates the <Term>Expected Information</Term> of each Guess, and plays the best Guess. The name of this Strategy is greedy, because it takes the best Guess for this step and does not plan further.

Each step uses the three ideas of this Part, in order. Find the Candidates. Make the Feedback Split of each Guess. Play the best Guess. That Guess is the <Term>Suggestion</Term>.

```python title="The greedy choice" {11-14}
def suggest(
    self,
    candidates: np.ndarray,
    *,
    pool: Pool = "guesses",
    scope: Scope = "global",
    by: Rank = "bits",
) -> WordStats | None:
    """The Suggestion: the top-ranked Guess, or None if no Candidate is left."""
    # With one or two Candidates, guessing one of them is never worse.
    if 0 < len(candidates) <= 2:
        scope = "candidates"
    best = self.rank(candidates, pool=pool, scope=scope, by=by, top=1)
    return best[0] if best else None
```

The loop around `suggest` is short. Play the Suggestion, use its Feedback to find the new Candidates, and do it again:

```python
game = Game("watch")
candidates = solver.all_candidates()
while not game.is_over:
    guess = game.guess(solver.suggest(candidates).word)
    candidates = solver.narrow(candidates, guess.word, pack(guess.feedback))
```

## A Guess that can't win

One setting of `suggest` has a large effect: `scope`, the <Term>Search Scope</Term>. The Solver can search only the Candidates. Or it can search **All words** on the Guess List, which includes words that cannot be the Answer.

To play a word that cannot win looks like a waste. But it can be the best question. A Game with the Answer <Word>watch</Word> shows why.

First, the Solver searches Candidates only, and its <Term>Guess Pool</Term> is the Answer List. Step through the Game:

<StepThroughGame id="trap" answer="watch" pool="answers" scope="candidates" step={4} />

<Word>raise</Word>, <Word>tangy</Word> and <Word>caput</Word> make the Candidate Set 5 words: <Word>batch</Word>, <Word>hatch</Word>, <Word>latch</Word>, <Word>match</Word> and <Word>watch</Word>. All five words fit <Word>_atch</Word>. Now the Solver must guess one of them, and each one is a bad question. If you guess <Word>batch</Word> and it is not the Answer, you learn only that the first letter is not <Letter>b</Letter>. The best Candidate gives only 0.72 bits, and its largest group has 4 words. So the Solver guesses <Word>batch</Word>, <Word>hatch</Word>, <Word>latch</Word> and <Word>match</Word>, one at a time. <Word>watch</Word> needs **eight** Guesses. The Guess Limit is six, so that Game is a <Term>Loss</Term>. <Word>match</Word> needs seven, and it is also a Loss.

This is the <Word>_atch</Word> trap. A family of words that are different in only one letter is a trap for each Strategy that guesses only Candidates, because each Candidate removes only itself.

Now take the same Answer, and let the Solver search All words on the Guess List:

This time, the Solver starts with <Word>tarse</Word>. With 5 Candidates left, it plays <Word>abamp</Word>. <Word>abamp</Word> is an unusual word, and it cannot be the Answer. But it contains <Letter>b</Letter>, <Letter>m</Letter> and <Letter>a</Letter>, so it asks four questions with one Guess. Its Feedback separates the family, and the Solver wins with 5 Guesses. <MarginNote>Follow <Word>watch</Word> with this Strategy on the [Follow an Answer page](/follow?answer=watch&pool=guesses&scope=global&by=bits), and see the Candidates left after each Guess.</MarginNote>

The numbers show the same thing for these 5 Candidates. A Candidate such as <Word>batch</Word> is worth 0.72 bits, and it leaves 3.4 words on average. The best word on the full list, <Word>ablow</Word>, is worth 1.92 bits and leaves 1.4 words on average, with no group larger than 2. <Word>ablow</Word> cannot win now, but it almost makes sure of a win with the next Guess.

So remember this: **a Guess that cannot win can still be the best Guess.** When the Solver searches all words, eight Guesses become five. The `if` near the end of `suggest` adds one more detail. With one or two Candidates left, the Solver goes back to Candidates only, because then to guess one of them is never worse.
