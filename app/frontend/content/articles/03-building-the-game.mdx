The last two Articles gave the rules and the Feedback function. With them, you can build the full <Term>Game</Term>. The Game needs three small parts: a <Term>Guess</Term>, a <Term>State</Term> and the Game itself.

## A Guess and the State

In the code, a Guess is a word, its Feedback and its number in the Game. The <Term>State</Term> is all the Guesses so far, each with its Feedback. The State is all that a player, or a Solver, can see.

```python title="A Guess and the State" {8-9,16-17}
@dataclass(frozen=True)
class Guess:
    number: int
    word: str
    feedback: Feedback

    @property
    def is_win(self) -> bool:
        return all(mark is Mark.CORRECT for mark in self.feedback)


@dataclass(frozen=True)
class State:
    guesses: tuple[Guess, ...] = ()

    def add(self, word: str, feedback: Feedback) -> "State":
        return State(self.guesses + (Guess(len(self.guesses) + 1, word, feedback),))
```

A Guess is a <Term>Win</Term> when all five Marks are <Mark kind="correct" />.

Both classes are frozen, and `add` does not change the State. It makes a new State. So if you keep a State, it stays the same while the Game continues. The Solver needs this later.

## The Game

The Game holds the Answer, the <Term>Guess Limit</Term> and the current State. The Game also decides when it is over.

```python title="The Game" {4,9,13,16-19}
@dataclass
class Game:
    answer: str
    max_guesses: int | None = MAX_GUESSES
    ...

    @property
    def is_won(self) -> bool:
        return self._state.last is not None and self._state.last.is_win

    @property
    def is_lost(self) -> bool:
        return not self.is_won and self.guesses_left == 0

    def guess(self, word: str) -> Guess:
        if self.is_over:
            raise GameOver("the Game is already over")
        word = self.check_guess(word)
        self._state = self._state.add(word, feedback(word, self.answer))
        return self._state.last
```

`guess` does three steps:

1. If the Game is already over, it raises `GameOver`.
2. `check_guess` makes sure that the word has five letters and is on the <Term>Guess List</Term>. If not, it raises an error, and the word does not count as a Guess.
3. The `feedback` function from the last Article gives the Feedback, and `add` puts the Guess into a new State.

A <Term>Loss</Term> is a Game that reached its Guess Limit without a Win. If you set `max_guesses=None`, the Game has no Guess Limit, so it can only stop with a Win.

## The loop

Now a Game is a loop. Ask for a word, guess it, show the State, and stop when the Game is over:

```python
game = Game("crane")
while not game.is_over:
    word = input("Guess: ")
    try:
        game.guess(word)
    except InvalidGuess as error:
        print(error)
        continue
    print(game.state)
print("Win" if game.is_won else f"Loss: the Answer was {game.answer}")
```

If you type `zzzzz`, the loop prints `'zzzzz' is not on the Guess List`, and you keep all your Guesses. If you type `crane`, the loop prints five <Mark kind="correct" /> tiles and a Win.

That is the full game. The rest of the Series is about the player, and how it picks each Guess.
