Each <Term>Feedback</Term> removes some words. The words that remain are the <Term of="Candidate">Candidates</Term>, and all of them together are the <Term>Candidate Set</Term>. This Article gives the exact test for a Candidate, and shows how fast the Candidate Set gets smaller.

A word is a Candidate if it can still be the Answer. To test a word, use it as the Answer and work out the Feedback that each Guess in the <Term>State</Term> would get. If all of these Feedbacks are the same as the Feedbacks that the game showed, the word is a Candidate. If one of them is different, the word is not a Candidate.

Only words from the <Term>Answer List</Term> can be Candidates. This is also true when a Guess is an unusual word that can never be the Answer. At the start of a Game, before the first Guess, the Candidate Set is the full Answer List: 2,315 words.

## Watch it shrink

Let the Answer be <Word>abide</Word>. The first Guess is <Word answer="abide">crane</Word>. The Feedback is <Mark kind="absent" /> for <Letter>c</Letter>, <Letter>r</Letter> and <Letter>n</Letter>, <Mark kind="present" /> for <Letter>a</Letter> and <Mark kind="correct" /> for <Letter>e</Letter>. That leaves 49 Candidates. The second Guess is <Word answer="abide">pilot</Word>. Of its letters, only <Letter>i</Letter> is in <Word>abide</Word>, and not in the second position. So <Letter>i</Letter> is <Mark kind="present" /> and the other four letters are <Mark kind="absent" />. Now only 4 Candidates remain: <Word>abide</Word>, <Word>aside</Word>, <Word>maize</Word> and <Word>waive</Word>.

## The same test in Python

The definition is also the code. Keep each Answer List word that would give every Feedback in the State. The `feedback` function comes from the Feedback Article:

```python
def candidates(state, answers):
    return [
        answer
        for answer in answers
        if all(feedback(guess.word, answer) == guess.feedback for guess in state)
    ]
```

The package does the same work, but much faster. To work out each Feedback again, for each word at each step, is slow. So the package finds each Feedback in a <Term>Feedback Matrix</Term>. This is a table of the Feedback of every Guess against every Answer, and the package fills it once, before any Game:

```python title="Narrowing the Candidates" {4-5}
def narrow(self, candidates: np.ndarray, guess: str, code: int) -> np.ndarray:
    """The Candidates that would have given Feedback Code `code` for `guess`."""
    row = self.guesses_vs_answers[self._guess_row[guess]]
    return candidates[row[candidates] == code]
```

The important line is the last one. It keeps each Candidate whose cell in the Guess's row is equal to the Feedback that the game showed.
