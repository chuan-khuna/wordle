# Implementation documents

How this project is built. Domain terms are defined in [GLOSSARY.md](../../GLOSSARY.md).

- [Architecture](architecture.md): the uv workspace, the `wordle` package's modules and layers, how to run, build and test it.
- [Feedback scoring](feedback-scoring.md): the two-pass rule that gives each letter its Mark, with repeated-letter examples.
- [Game and State](game-and-state.md): the `Game`, `Guess` and `State` classes, guess validation, Seeds, the Guess Limit, Win and Loss, and trying words after a Game ends.
- [Terminal UI](terminal-ui.md): the questionary menus, the rich board and keyboard, the share grid, replaying a Game by its Seed, and how to drive the UI from a script.
- [gpui desktop app](gpui-app.md): the Rust + gpui window in `app/wordle-gpui/`: its module layout (engine, solver, overlays, ui), the Solver panel with its Feedback Split chart, Solver mode for a Wordle played elsewhere (Feedback clicked in by hand), the settings menu and command palette, live hints, the sidebar's Oxford dictionary lookups, how to run it with `just`, and how its Seeds match the Python game.
- [Feedback matrices](feedback-matrices.md): the precomputed Answer × Answer and Guess × Answer Feedback matrices, their cell encoding, why `.npy`, and how Python and the gpui app regenerate them.
- [Solver Strategy](solver-strategy.md): how the Solver scores Guesses by Expected Information and Expected Candidates from the matrices, its pool and scope options, how it differs from the reference project, and the Answers (with Seeds) a Candidates-only search fails on.
- [Web backend](web-backend.md): the FastAPI project in `app/backend/`, which reuses the `wordle` package's engine through a uv path dependency: its layout (`main.py`, `routers/`, shared `common.py`, the `WebSolver` wrapper), the precompute command and its Feedback matrices, the precomputed Benchmark and Opener leaderboard (three Strategies, results), the JSON API (endpoints, Marks as digit strings, 400 and 503 errors), and how to run and test it.
- [Web frontend](web-frontend.md): the Next.js app in `app/frontend/` (App Router, TypeScript, Tailwind, bun with a 7-day minimum release age): its layout, `just frontend` and `just web`, the `/api` rewrite to `BACKEND_URL`, and the ten gpui themes as CSS variables and Tailwind colours with a no-flash picker saved in `localStorage`; and the Articles and Series pipeline (MDX with KaTeX, frontmatter, Prerequisites, backlinks, prev/next, video timestamps, build-time validation) and the `<Term>` glossary component; and the Widgets (Feedback scorer, Candidate filter, Feedback Split explorer, Step-through Game, Opener table, Benchmark chart): props, URL params that override them, `id` namespacing, the TypeScript Feedback port, and the TanStack Charts setup (theme-role colours, SSR).
